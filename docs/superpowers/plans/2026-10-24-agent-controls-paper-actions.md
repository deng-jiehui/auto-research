# 会话模式按钮与论文快捷归档实施计划

**目标：** 用户在输入框上方选择单 Agent 或多 Agent，并从检索结果一键加入项目论文库。

**实现：** 模式随发送请求提交并固定到 Turn；会话在浏览器保存偏好，默认从运行时读取。论文结构化元数据通过现有 academic.tool 事件返回；归档复用 POST papers 和按 source_key 去重，右侧面板读取项目论文。

**约束：** 仅修改 AutoResearch；保留工作树既有改动，不修改框架或用户密钥，不执行真实模型付费测试。运行中的 Turn 不因切换按钮改变模式。

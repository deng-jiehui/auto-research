# 编辑消息并重新执行实施计划

**目标：** 用户消息的刷新图标改为编辑图标；原位修改、取消或保存并重新发送。重新发送保留此前对话，替换当前回复并移除后续对话。

**边界：** 只修改 AutoResearch。沿用原 Turn 的模式和前置上下文，重跑使用独立检查点；不撤销已保存的论文、项目笔记或文件修改。不使用真实模型测试，不创建新后台服务占用用户端口。

**文件职责：** `turns.go` 与 HTTP 接口负责输入校验和重新执行；SQLite 事务负责原消息更新、后续消息失效和排队；`SessionPage.tsx` 负责原位编辑和新快照展示。旧轮保留内部记录，但不再进入可见对话和后续上下文。

- [x] HTTP 集成测试先复现已完成任务不能重试，覆盖编辑、后续对话替换、幂等与作用域。
- [x] SQLite 原子更新原消息、标记被替换的消息和后续轮次，拒绝执行中编辑，清空旧错误和待回答问题。
- [x] 为每次重跑建立独立检查点，隔离旧回答和旧中断；快照只展示当前执行的业务结果。
- [x] 编辑按钮、预填文本框、取消、保存并重新发送；空文本禁用，提交失败保留编辑内容。
- [x] Playwright 使用临时服务和本地模型验证取消、修改、真实再次调用、旧内容消失与刷新持久化。
- [x] Go 测试/vet、前端测试/构建、浏览器回归和使用文档。
